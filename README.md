# OBD11 Bypass iOS 14

Keeps older **OBDeleven** apps working on **rootful iOS 14**.

Supports **OBDeleven 1.2.1 (BMW)** and **OBDeleven VAG 1.9.28**. It spoofs the app version/build, moves the old Parse connection to the current server.

Both apps have their own enable, version and build settings. No free credits or paid features are added. This is just to get your apps working again.
